# 🚀 Quick Start Guide - Calendar PWA

Get started in **2 minutes**!

## ⚡ Fastest Way to Run

### Option 1: Python (Recommended)
```bash
cd calendar-pwa
python3 dev-server.py
```
Browser opens automatically at `http://localhost:8000` ✨

### Option 2: Python Simple Server
```bash
cd calendar-pwa
python3 -m http.server 8000
# Open http://localhost:8000 in browser
```

### Option 3: Node.js
```bash
npx serve calendar-pwa
# Follow the URL shown in terminal
```

### Option 4: VS Code Live Server
1. Install "Live Server" extension
2. Right-click `index.html`
3. Select "Open with Live Server"

## ⚙️ Quick Settings

1. Click gear icon (⚙️) in header
2. Adjust:
   - **Hours:** When your day starts/ends
   - **Interval:** 15m, 30m, or 1h time slots
   - **Color:** Choose your favorite
   - **Theme:** Light or dark
   - **Layout:** Vertical or horizontal

All changes apply **instantly**!

## 🎯 Tips & Tricks

### Navigate Quickly
- **← →** arrows: Previous/next day/week/month
- **Layout icon:** Switch between daily/weekly/monthly
- **Monthly view:** Click any day to jump to it

### Daily View
- **Empty event + 🗑:** Deletes the slot
- **Filled event + 🗑:** Clears the text
- **Enter in tasks:** Creates new task

### Weekly View
- **+ button:** Quick add event for that day

### Settings
- **Ripristina:** Undo all changes
- **X:** Save and close

## ❓ Common Questions

### Where is my data stored?
In your browser's IndexedDB. It's like a mini database on your device.

### Can I access it offline?
Yes! After first visit, works 100% offline.

### Can I sync between devices?
Not yet - v1.0 is local-only. Cloud sync planned for future.

### Can I export my data?
Coming in future version! For now, data stays in browser.

### Does it work on all browsers?
Best on Chrome, Edge, Safari, Firefox. Needs modern browser.

## 🆘 Troubleshooting

### Nothing appears
1. Check browser console for errors (F12)
2. Try hard refresh (Ctrl+Shift+R)
3. Clear cache and reload

### Can't install as PWA
- Must be on HTTPS or localhost
- Some browsers need specific settings
- Try different browser

### Data disappeared
- Did you clear browser data?
- Different browser profile?
- Incognito mode? (Data not saved there)
