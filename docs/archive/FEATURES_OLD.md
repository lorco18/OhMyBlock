# Features

## Navigazione temporale
- navigazione avanti e indietro per giorno, settimana o mese
- titolo dinamico nel header
- mantenimento di ultima vista e ultima data aperta

## Gestione viste
- vista giornaliera
- vista settimanale
- vista mensile
- layout verticale o orizzontale

## Eventi
- creazione evento
- modifica evento
- eliminazione evento
- ordinamento automatico per data e orario
- supporto a eventi senza orario
- evidenziazione evento importante
- stato completato evento

## Task
- creazione task
- modifica task inline
- eliminazione task svuotando il testo
- stato completato
- ordinamento persistente tramite campo `order`
- riordino manuale con controlli su/giù

## Note
- note testuali salvate per data
- modifica inline con salvataggio automatico

## Pasti
- campi dedicati per:
- pranzo
- merenda
- cena

## Impostazioni
- ora iniziale griglia giornaliera
- ora finale griglia giornaliera
- intervallo slot orari
- colore principale
- font
- tema
- layout

## Backup
- export completo in JSON
- import completo da JSON
- sovrascrittura del database locale tramite import

## PWA
- manifest web app
- service worker registrato all'avvio
- icone app
- predisposizione uso mobile

## UX
- salvataggio automatico
- modali per operazioni principali
- supporto focus tastiera
- responsive desktop/mobile
- tema chiaro/scuro
