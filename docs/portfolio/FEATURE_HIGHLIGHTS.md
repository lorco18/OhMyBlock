# Feature Highlights

## Core Experience

### Three-view planning
- daily view per il dettaglio della giornata
- weekly view per la panoramica operativa
- monthly view per lettura rapida del carico del mese

### Local-first data model
- dati salvati in `IndexedDB`
- nessun account richiesto
- nessun backend necessario
- maggiore privacy per l'utente

### PWA behavior
- installabile come app
- supporto offline
- manifest e service worker inclusi

## Functional Highlights

### Event management
- creazione evento
- modifica evento
- eliminazione evento
- marcatura importante
- stato completato
- editing eventi direttamente dalla weekly view

### Task management
- task giornaliere e settimanali
- completamento rapido
- editing inline
- riordino manuale persistente

### Notes and meals
- note testuali per data
- gestione pasti: pranzo, merenda, cena

### Customization
- tema chiaro/scuro
- colore principale
- font
- layout verticale/orizzontale
- configurazione orari e intervalli agenda

### Backup
- export completo JSON
- import completo JSON
- ripristino locale dei dati

## Product Strengths

- interfaccia semplice e leggibile
- codice modulare e facilmente estendibile
- esperienza coerente tra viste
- buono per uso personale, demo tecnica o portfolio frontend
